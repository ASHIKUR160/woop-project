# $WOOP Cast-to-Earn Platform

🔥 **$WOOP** is a Cast-to-Earn and NFT minting platform where users can earn points and NFTs by sharing content on Warpcast.

---

## 🚀 Features

- ✅ Login with Warpcast username
- ✅ Earn points by casting
- ✅ Cast verification
- ✅ Mint NFTs
- ✅ Referral system (referrer points)
- ✅ Top 10 leaderboard
- ✅ Wallet integration (RainbowKit, wagmi)

---

## 🛠️ Technologies Used

- **Backend:** Node.js, Express, MongoDB, Axios
- **Frontend:** Next.js, React, RainbowKit, wagmi
- **(Optional Future)** Smart Contract: Solidity
